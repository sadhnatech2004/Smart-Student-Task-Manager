# Smart-Student-Task-Manager
A beginner friendly Java task management application that helps student organize assignments, track deadline, search tasks, and monitor completion status.
📚 Smart Student Task Manager

A simple task management application built using Java to help students organize their assignments and manage daily academic activities.

✨ Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Search tasks by name
- Track deadlines

🛠️ Technologies

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Git & GitHub

🎯 Project Objective

The objective of this project is to develop a simple task management system that helps students organize academic tasks while practicing Java programming and object-oriented concepts.

▶️ How to Run

1. Clone the repository.
2. Open the project folder in your Java IDE.
3. Compile the Java files.
4. Run "Main.java".
